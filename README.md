# Gestor-de-horarios-universitarios
Analiza horarios y crea mejores distribuciones para una persona

## Descripción del proyecto

El objetivo es el desarrolllo de un producto que permita a un usuario analizar posibles distintos horarios de diversas facultades de la UGR que se acomoden a sus necesidades durante el período correspondiente y buscando optimizar los mismos para evitar problemas como coincidencias horarias.

El producto buscaría tambien analizar estos horarios por subgrupos, por dobles grados o una o mas titulaciones y teniendo en cuenta la coincidencia de exámenes ordinarios y extraordinarios. 

### Apartado técnico

Los lenguajes de programación pensados para usar en el desarrollo del proyecto serán:
