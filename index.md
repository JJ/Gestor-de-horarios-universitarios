# Gestor de horarios universitarios

Aplicación para facilitar la consulta y organización de horarios universitarios.

## ¿Qué problema resuelve?

Permite centralizar la información de horarios y detectar posibles conflictos entre asignaturas.

## Funcionalidades

- Consulta de horarios.
- Detección de solapamientos.
- Organización de asignaturas.
- Apoyo a la planificación académica.
